CoCreate Wake Lock

Use wake-lock as a click toggle, or invoke the request and release methods through CoCreate Actions.

<button wake-lock="false" wake-lock-type="screen">Keep screen awake</button>
<button actions="wakeLock.request(screen)">Request</button>
<button actions="wakeLock.release">Release</button>

When no type is supplied, JavaScript defaults to "screen". The native sentinel is returned by the JavaScript API and its release event keeps the element state synchronized.

The current Screen Wake Lock API defines only the screen type. It requires a secure, visible page and can be released by the browser or operating system.
